# FareFinder India ✈️🇮🇳

> The Direct & Unbiased Flight Meta-Search Engine for India.

**FareFinder India** is an independent flight meta-search and fare discovery platform engineered for the Indian domestic aviation market. It connects Indian travelers directly with scheduled airlines and travel providers, allowing instant price comparison with full transparency on government GST, mandatory airport user development fees (UDF/PSF), baggage allowances, and student concessions.

---

## 🌟 Platform Highlights

- ✈️ **Comprehensive Domestic Coverage**: Compare flight timings and airfares across major Indian carriers including IndiGo, Air India, Akasa Air, Air India Express, and SpiceJet.
- 🔍 **True Total Pricing**: Always displays the exact final fare inclusive of base fare, DGCA-mandated airport taxes (UDF, PSF), and GST with zero hidden fees.
- 🎓 **Student Concession Finder**: Verified search filter for eligible students with automated 10% base fare concessions and +10kg complimentary baggage allowance.
- 🔀 **Single Grouped Flight Cards**: Eliminates clutter by grouping identical physical flights into a single card with side-by-side provider comparison.
- 🛡️ **Zero-Markup Direct Referrals**: FareFinder does not sell tickets or process payments. Travelers are referred directly to official airline booking channels to complete reservations.
- 📈 **Price History & Trends**: Visual 30-day route price trends to help travelers identify the optimal booking window.
- 🔔 **Route Price Drop Alerts**: Automated tracking for popular domestic corridors with instant threshold alerts.
- 🌙 **Modern Dark-Mode Experience**: High-contrast, mobile-first responsive design engineered for fast searches on any device.

## 🛠️ Local Development & Deployment

### Prerequisites
- Node.js 20.x or higher
- npm 10.x or higher

### Setup

```bash
# 1. Clone repository
git clone https://github.com/YOUR_USERNAME/farefinder.git
cd farefinder

# 2. Install dependencies
npm install

# 3. Launch local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Production Build

```bash
# Compile optimized production bundle
npm run build

# Start production server
npm run start
```

### Automated Testing

```bash
# Run test suite
npm run test
```
